# AI Agent & Contributor Instructions

This repository contains two isolated workspaces: backend/ and frontend/.

## Mandatory Directives Before Making Any Changes
- Backend agents: Read backend/AGENTS.md and backend/docs/ARCHITECTURE-RULES.md
- Frontend agents: Read frontend/AGENTS.md and frontend/docs/ARCHITECTURE-RULES.md
- Do NOT merge package.json files across workspaces.
- Do NOT bypass RabbitMQ for direct service HTTP calls.
- Do NOT mix Super DB and tenant DB collections.
