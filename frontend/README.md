# Tribyte360 Frontend Workspace

Next.js 14 + Turborepo monorepo.

## Independent Apps
- `apps/ams` — Asset Management System
- `apps/admin` — Super Admin Portal
- `apps/customer` — Tenant Customer Portal

## Shared Packages
- `packages/ui` — shadcn/ui Design System & Lucide Icons
- `packages/tenant` — Subdomain Resolution Engine
- `packages/api-client` — Multi-Tenant REST API Client
